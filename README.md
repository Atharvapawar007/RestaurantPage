# 🍻 The Odin's Inn

A modern restaurant homepage built as part of **The Odin Project's JavaScript Course**. This project demonstrates how to build a fully dynamic single-page application (SPA) using **JavaScript modules**, **Webpack**, and **DOM manipulation**, without relying on any frontend frameworks.

Inspired by Nordic taverns and Viking culture, **The Odin's Inn** features a cinematic design with a modular architecture and dynamic page rendering.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/RestaurantPage.git
```

Navigate into the project

```bash
cd RestaurantPage
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

Build the production bundle

```bash
npm run build
```
